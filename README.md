# 🛡️ Dependability analysis of critical cyber-physical systems using SysMLv2 and simulation

[![License: CC BY-NC 4.0](https://img.shields.io/badge/License-CC%20BY--NC%204.0-lightgrey.svg)](https://creativecommons.org/licenses/by-nc/4.0/)

This repository contains the models and source codes of my Master's thesis design. The project focuses on the dependability analysis of critical cyber-physical systems by integrating modern system modeling (SysMLv2) and simulation (Modelica) tools.
    
## 📂 Repository Structure

The project consists of three main components:

* **`sysmlv2/`**: SysMLv2 libraries and models describing the system architecture and dependability requirements.
* **`modelica/`**: Modelica models that serves as basic examples and as case studies for the thesis.
* **`scripts/`**: Python scripts responsible for automation with Syside Automator, co-simulation mapping, and running the analysis (e.g., fault injection, evaluation).
